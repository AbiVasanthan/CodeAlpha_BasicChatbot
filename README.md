CodeAlpha_BasicChatbot

A simple rule-based chatbot made with Python.

About
The bot reads what the user types and replies using predefined responses. It does not use AI. It works with `if-elif` conditions, a function and a loop.

Features
- Greetings (hello, hi, good morning, good night)
- Small talk (how are you, your name, who made you)
- Tells the current time and date
- Tells a joke and a fun fact
- Replies to thanks and says goodbye
- Gives a default reply when it does not understand

Concepts used
- `if-elif-else` statements
- Functions
- `while` loop
- Input and output
- `datetime` module
